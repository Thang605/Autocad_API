## 2024-03-24 - [Avoid O(N) ModelSpace iterations by using SelectionFilters]
**Learning:** In AutoCAD .NET development, iterating through all entities in the ModelSpace BlockTableRecord (`foreach (ObjectId id in btr)`) is a major performance bottleneck, resulting in an O(N) operation where N is the total number of entities in the drawing. This can freeze the UI and significantly slow down command execution on large drawings.
**Action:** Instead of iterating through ModelSpace, use `Editor.SelectAll(SelectionFilter)` whenever an Editor is available to let AutoCAD's internal optimized C++ spatial index do the filtering. Alternatively, if no specific user interaction is required and it's a batch process, rely on `RXClass` type checking before `tr.GetObject()` to minimize transaction overhead.
