## 2024-05-24 - [Iterating ModelSpace without Editor.SelectAll()]
**Learning:** In AutoCAD, iterating over `btr` (BlockTableRecord representing ModelSpace) using a `foreach` loop to find entities of a certain type (`id.ObjectClass.Name == "AeccDbAlignment"`) takes O(N) time and requires creating/checking a large number of ObjectId instances. When an `Editor` and `SelectionFilter` cannot be used, using `A.Cdoc.GetAlignmentIds()` is much faster and directly fetches the objects of the desired type from the Civil 3D Document object without scanning the entire model space.
**Action:** Replace `foreach (ObjectId id in btr)` scanning in `KiemTraProfileForm.cs` and `KiemTraTimTuyenForm.cs` (and any similar UI form `LoadAlignments` methods) with `CivilApplication.ActiveDocument.GetAlignmentIds()`.
