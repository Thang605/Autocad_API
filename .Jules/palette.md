## 2024-05-18 - Missing Keyboard Shortcuts in WinForms
**Learning:** Many WinForms dialogues in this repository lack keyboard accessibility shortcuts (Enter to accept, Escape to cancel), which forces mouse interaction and degrades user experience. According to AGENTS.md, WinForms accessibility is a priority.
**Action:** Add AcceptButton and CancelButton properties mapping to OK/Execute and Cancel/Close buttons in forms.
